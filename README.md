# 📝 Todo App

A simple and responsive Todo application built using **HTML**, **CSS**, and **JavaScript**. The app allows users to manage daily tasks with features like adding, editing, deleting, filtering, and storing todos using the browser's Local Storage.

---

## 🚀 Features

- ✅ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✔️ Mark tasks as completed
- 🔍 Filter tasks (All, Active, Completed)
- 🧹 Clear all completed tasks
- 💾 Persistent storage using Local Storage
- 📊 Active task counter
- 📱 Responsive design
- 🔒 Basic protection against HTML injection

## 📸 Features Overview

### ➕ Add Task
Create a new task by entering text and clicking the **Add** button or pressing **Enter**.

### ✏️ Edit Task
Click the **Edit** button to modify an existing task, then click **Save** or press **Enter** to save your changes.

### ✔️ Complete Task
Mark tasks as completed using the checkbox.

### 🗑️ Delete Task
Delete any task permanently with a single click.

### 🔍 Filter Tasks
View tasks by their status:

- All
- Active
- Completed

### 🧹 Clear Completed
Remove all completed tasks at once.

### 💾 Persistent Storage
All tasks are automatically saved in your browser's Local Storage, so your data remains even after refreshing or closing the browser.

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/kumarsusheel7497-collab/todo-app.git
```

2. Navigate to the project folder:

```bash
cd todo-app
```

3. Open the `index.html` file in your preferred web browser.

No installation or external libraries are required.

---

## 💻 Usage

1. Enter a task in the input field.
2. Click **Add** or press **Enter**.
3. Mark tasks as completed using the checkbox.
4. Edit tasks whenever required.
5. Delete tasks you no longer need.
6. Use the filter buttons to view specific tasks.
7. Clear all completed tasks using the footer button.
